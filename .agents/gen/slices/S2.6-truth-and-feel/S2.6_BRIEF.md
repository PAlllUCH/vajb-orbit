## The pinned interface (CONTRACTS §14 is the source of truth; nothing here may drift)

```gdscript
# game/asteroid.gd — additive
const FRAGMENT_OUTWARD_KICK := 150.0  # u/s, added along the outward radial
# fragment velocity = rolled_dir × (|linear_velocity| × FRAGMENT_EJECT_MULT)
#                   + outward_dir × FRAGMENT_OUTWARD_KICK
# outward_dir = (spawn_pos - rock_centre).normalized(); reversal: 0.0 = today exactly

# game/weapons.gd + game/mining_laser.gd — additive
const BEAM_SINK := 0.45               # drawn end = hit_point.lerp(body_centre, 0.45)
const HIT_FX_JITTER_MULT := 0.35      # jitter disc = clamp(0.35 × collision radius, 8, 48) u

# game/ship_fit.gd — the HANDLING derivation gains two multipliers (the §4 pattern)
const ACCEL_TIME_MULT := 2.0          # accel_time rows × 2.0 — reversal 1.0
const COAST_TIME_MULT := 2.0          # TODAY's coast_time rows × 2.0 = §13's own column
                                      # (the documented revert of the combat wave's ×0.50)
const TURN_TRANSLATE_LEAK_MAX := 5.0  # u displacement per full 360° neutral turn at zero throttle
# mirrored maneuvers must produce mirrored trajectories within 1 %

# game/speed_fantasy.gd / speed_blur.gdshader
const SPEED_BLUR_EXCLUDE_PLAYER := true  # the hull renders sharp outside the blur pass

# tests/headless_runner.gd — at runner boot, before any suite
PlayerProfile.save_path = "user://_gate_scratch/profile.cfg"  # + seed a deterministic default profile
```

Rules that fix every ambiguity:
- The flight multipliers are **derived, one constant each** — never hand-edit a
  per-class row. `max_speed` never moves; only time-to-speed and decay do.
- The neutral-turn fix separates rotation from translation at the command seam:
  a turn input applies torque only. The symmetric-slide fix is at the same seam —
  if the root cause is elsewhere, **report it in the worker report and fix it
  there**, never mask it with a counter-force.
- The blur exclusion is render-side only: no FX sheet, blend mode or speed-fantasy
  number moves (§5's inputs stand).
- The fragment kick is **additive on top of** §5's shape — the 360° spread and the
  ×1.2 inherit stay measurable. Rock yields, splits and the break read do not move.
- `BEAM_SINK` applies to the drawn line only — the damage ray resolves at the
  surface hit point. Jitter applies to FX spawn positions only, never damage.
- The harness sandbox is host-independent (no `XDG_DATA_HOME` in the contract);
  §9's command text does not change.
- The four coupled tests build their own fit fixtures or derive expectations from
  the launched fit (`test_engine2_wiring`'s becomes "every weapon the launched fit
  mounts is in `fitted()`"). Assertions keep their meaning; only fixtures change.
