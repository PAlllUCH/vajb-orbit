## Step 3 — `autoload/audio_manager.gd`: music and ambience

Today there is only `play_ui` / `play_sfx` and no music or ambience API at all, so 93 of the 95 shipped audio files are unreachable. Add exactly these public methods, keeping the existing style (typed, no `print()`, the existing cue resolution rule of exact filename first then the `_01` fallback):

```gdscript
func play_music(track: StringName, fade_seconds: float = 1.0) -> void
func stop_music(fade_seconds: float = 1.0) -> void
func current_music() -> StringName
func play_ambience(bed: StringName, fade_seconds: float = 1.0) -> void
func stop_ambience(fade_seconds: float = 1.0) -> void
func current_ambience() -> StringName
```

- Music plays on a dedicated `AudioStreamPlayer` on the `Music` bus; ambience on a dedicated one on the `SFX` bus. Both loop (`stream.loop = true`) and both are created in `_ready()` alongside the existing players.
- A fade is a `Tween` on `volume_db` from `-80` to the value the bus volume implies (read the bus linear volume through the existing `bus_linear`, and honour a muted bus by leaving the player silent rather than raising an error). Re-calling `play_music` with a different track must crossfade, not stack; calling it with the currently playing track must be a no-op.
- The cue directory comes from `Paths.AUDIO_DIRS`: music under `&"music"`, ambience under `&"ambience"`. A parallel worker adds the `&"ambience"` key to `ui/paths.gd`; if it is not there yet when you read the file, write your code against the key `&"ambience"` anyway and note it in your report. Do not edit `ui/paths.gd`.
- A missing file must be a silent no-op, matching the existing documented behaviour ("every cue is a silent no-op until its file exists").
- The existing `SettingsManager` bus-volume path must keep working untouched: do not change `set_bus_linear` / `bus_linear` semantics.
