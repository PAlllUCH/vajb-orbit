# R1 evidence — the save v5 flag day on a real boot, from R1's own hand-written v4 file

The fixture below was written by hand (not by the code under test), the boot scene is the shipped one, and the profile is sandboxed.

```text
# the fixture, written by hand into the sandbox before the boot (the boot sweeps it to v5):
$ cat > /tmp/r1_boot/godot/app_userdata/"Vajb Orbit"/profile.cfg <<'EOF'
[profile]

save_version=4
credits=4321
owned_ships=["ship_vanguard"]
active_ship="ship_vanguard"
upgrades=["upgrade_generator", "upgrade_shield", "upgrade_engine", "upgrade_module", "upgrade_extra", "upgrade_drone"]
EOF

$ XDG_DATA_HOME=/tmp/r1_boot godot --headless --path vajb-orbit res://ui/screens/boot.tscn --quit-after 400   # exit 0
$ rg -n "upgrade" <the file after the boot>   # exit 1 = no token
exit=1
$ rg -n "save_version|modules" -A 20 <the file after the boot>
```
