# UI / HUD Art Scouting — CC0 Candidates

Research date: 2026-09-16. Scope: sci-fi HUD frames and panels, health/energy/shield bars, minimap frames and markers, target reticles, progress bars, sci-fi display fonts.
Constraint: **CC0 only** (see `docs/ASSETS.md`). GPL, CC-BY, CC-BY-SA and OGA-BY entries are rejected even when visually strong.
Method: `assetmcp` search tools (`search_assets`, `search_kenney_assets`, `search_opengameart`, `search_openverse_images`) plus direct page reads of every candidate. **Nothing was downloaded.**

## Summary

- The project's style baseline (Kenney flat vector) is also the best-covered licence territory. **Kenney UI Pack - Sci-Fi** is the single best pick: glass and metal panels *with dedicated corner sprites* (natively nine-slice-ready), horizontal and vertical bar pieces in 6 colours, crosshairs, plus PNG and vector sources. It covers frames, panels, bars and reticles in one consistent family.
- **Wenrexa's "Assets: UI Minimalism SciFi"** (OpenGameArt, CC0) is the strongest non-Kenney add-on: 33 sliced PNG elements plus a layered 1920x1080 PSD, explicitly sci-fi/minimalist, panels + bars + buttons. Its sibling "Free UI Hologram Interface" (same author, CC0) supplies holographic HUD dressing.
- Bars are over-supplied. Beyond Kenney's own bar strips, three CC0 OGA sets (arkalain's layered SVG, Aleh Lipka's bars sheet, ChaosRobH's glass bar system) are drop-in. arkalain's is vector and therefore res-independent.
- **Minimap frames are the weakest area.** Kenney's "Minimap Pack" is 8x8 pixel art and clashes with the flat vector baseline. The practical route is a nine-sliced Kenney Sci-Fi panel as the minimap frame, plus a CC0 radar disc/sweep (Prime_8, "Radar parts", written for Godot and meant to be modulated) and small icons in place of dedicated markers.
- **Reticles are fully covered** by Kenney Crosshair Pack (CC0, 64x64 tile size, ~200 files, vector variants and glow), with a second CC0 set (11 reticles, `crosshairs.zip`) as backup.
- **Fonts: only the Kenney family and `Boxfont Vector` are CC0 TTFs found.** The project already ships `kenvector_future`; Kenney Fonts adds the rest of that family (High Square, Rocket, Mini Square), and Boxfont Vector is the one genuinely different CC0 futuristic display TTF. No CC0 numerals-specific "damage number" font surfaced.
- Rejections are dominated by CC-BY/OGA-BY near-misses (CraftPix's space GUI and space icons, "Moderna Graphical Interface", "Grid HUD", "game_hud") and by CC0-but-pixel-art packs that clash with the flat vector baseline (Buch's sci-fi UI sets, `Freeport Monospace`).
- Openverse returned 0 results for CC0 sci-fi HUD imagery, and `search_assets` (normalised multi-source search) returned nothing for these queries; Kenney + OpenGameArt covered the whole space.

## Recommendations

1. **Adopt `Kenney UI Pack - Sci-Fi` as the HUD art baseline.** It is the only CC0 pack that provides panels *with corner sprites* (so Godot `NinePatchRect` works immediately), matching `barHorizontal_*_left/mid/right` and `barVertical_*_top/mid/bottom` strips in six colours, and crosshairs in the same visual language. Nine-slice the glass panels for the HUD frame, use metal panels for solid side bars, and map blue/green/red bar strips to shield/energy/hull.
2. **Layer `Wenrexa — Assets: UI Minimalism SciFi` (CC0) on top** for window/modal panels, buttons and 1080p-sized elements. Normalise its outlines and colour ramp against Kenney before committing, since it is hand-drawn rather than flat-vector.
3. **Bars: prefer Kenney's strips, keep arkalain's SVG as the res-independent fallback.** If the final HUD ships above 1080p, arkalain's layered SVG (background / fill variants / frame / marker) scales without artefacts.
4. **Reticles: Kenney Crosshair Pack**, using the vector variants for the main target bracket at 1080p+. Backup: `crosshairs.zip` (CC0, 11 reticles).
5. **Minimap: compose it, don't source it.** Nine-slice a Kenney Sci-Fi glass panel as the frame, drop in `Prime_8` radar parts (CC0, authored for Godot modulation) as the disc/sweep, and use small tinted Kenney dots/squares or Game Icons as vessel/station markers. Skip Kenney's Minimap Pack (8x8 pixel art, style clash).
6. **Full-screen readouts: `Sci-Fi interface textures` (rubberduck, CC0)** for station screens, settings/preferences backgrounds and behind-HUD detail. Treat it as art, not as tiled panels.
7. **Fonts: no new licence needed for the primary face** — `kenvector_future` is already in the project. Add Kenney Fonts (CC0) for secondary weights, and `Boxfont Vector` (CC0 TTF) if a distinct display face is wanted. Still no CC0 numerals-specific "damage numbers" face; use the numbers from the Kenney/Boxfont set and tint/scale them instead.
8. **Input Prompts (Kenney, CC0)** when the docking/abilities tutorial needs keyboard and gamepad glyphs; it is the only CC0 source for that, and it is the same visual family.
