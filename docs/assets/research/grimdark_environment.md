# Vajb Orbit — Grimdark Space Environment Art Research

Date: 2026-09-16 · Scope: free CC0 grimdark space environment art for a 2D top-down Dark Orbit clone (Godot 4.7.2, Forward+).
Style baseline: Kenney flat vector (Space Shooter Redux/Remastered) plus the CC0 environment packs already inventoried in `environment.md`.
Policy reference: `docs/ASSETS.md` (CC0-only; CC-BY is an exception that needs an exact credit string).
Companion (do not duplicate): `environment.md` — its candidates are deliberately not repeated here. Rows below that mirror one of its packs are marked as such.

## Method

1. **OpenGameArt, CC0 facet only.** 22 advanced-search queries with `field_art_licenses_tid[]=4`, several constrained to `field_art_type_tid[]=9` (2D Art): `nebula, wreckage, debris, destroyed, dark space, hulk, burnt, dead planet, ruins, derelict, graveyard, mining, wreck, planets, black hole, asteroid, parallax, supernova, abandoned, scrap, eclipse, gas giant, void, battleship, crashed, space station, salvage, starfield`, plus page 2 of `dark space`.
2. **Every candidate page was opened and its license read.** Two independent page reads were used per candidate: (a) raw page fetch (badge, author, description, file list), (b) extraction over the page HTML of the licence badge asset and licence URL — e.g. `sites/default/files/license_images/cc0.png` + `creativecommons.org/publicdomain/zero/1.0/`. Any page exposing **more than one** badge was treated as ambiguous and rejected.
3. **Kenney catalogue** crawled (queries `space`, `star`, `planet`).
4. **Openverse** could not be queried: the API returns `401 Unauthorized` (auth now required for `api.openverse.org/v1/images`) and the openverse.org search UI returns `403` to non-browser fetches. **No Openverse candidate was verified in this pass** — this is an evidence gap, not a claim that Openverse is empty. `environment.md:44` still holds the only Openverse-derived (NASA/Flickr) entry.
5. **itch.io** searched (`space background cc0`, free only): results are author profile pages with no licence field, and no located page states CC0 in writing, so nothing from itch is recommended (unchanged from `environment.md:78`).
6. **Nothing was downloaded.** No file in this report was fetched or extracted.

Scoring, two axes (both 1-5):

- **Flat-vector fit** — how close the art sits to the Kenney flat-vector baseline *after darkening*: 5 = vector/flat-shaded or tintable greyscale, 4 = cartoon flat, 3 = soft-shaded render, 2 = photographic/3D render, 1 = pixel art or photoreal photography.
- **Grimdark fit** — standalone ability to carry black / dying-nebula / dark-red / ash mood without treatment: 5 = already grimdark, 3 = neutral and needs a grade, 1 = cheerful.

## Summary

- **Grimdark CC0 space *environment* art is thin, and the thinness is structural.** The vocabulary Dark Orbit wants ("space hulk", "wreckage field", "dying nebula") returns almost nothing in CC0: `hulk` returns **0 assets**; `salvage` 2 (both unrelated); `wreckage` 3 (two audio, one single small sprite); `derelict` 3 (all audio/music); `graveyard` 36 (almost all audio and cemetery tilesets); `destroyed` 40 (no ship debris). There is **no CC0 derelict capital-ship, no hulk interior, and no dark-red nebula pack** on OpenGameArt.
- **The single best true wreckage find is Spacewreck (City Building Game Art):** a 2048×2110 PNG of a *"mangled and completely destroyed space structure with spinning boulders"*, plus Blender source and separate rotating boulder sprites. It is the only asset found that reads as a wreckage field at playfield scale.
- **The cheapest route to grimdark is treatment, not reskin.** Screaming Brain Studios' *Horror Texture Pack* (CC0, 300 textures at 128/256/512) includes **15 transparent stain overlays** for grime and bloodstains, plus rusted-metal, decaying-wall and crumbling-stone tiles; *Burnt Coal Ashes Tiling 1024* (CC0) is a seamless ash surface. Overlaid on the existing Kenney baseline and Rawdanitsu starfields these give an ash/dark-red grade **without abandoning flat-vector art**, which is exactly the two-axis compromise asked for.
- **Dark backdrops do exist, in three tiers of quality:** intentionally dark starfields (*Space Backdrop*, beren77, "intentionally very dark, subtle colors"), **tileable** starfields (*Space Backgrounds 9*, Rawdanitsu — three `-Tiled` PNG variants up to 10.4 MB), and 4K wallpapers (*Space Backgrounds in 4K*, Wenrexa, JPG).
- **Vector options for exact palette matching:** two CC0 SVG kits — SpriteAttack's vector space-background artpack and CruzR's Galaga-style *Space Starter Kit* — can be recoloured to a dark-red/ash palette pixel-exactly alongside Kenney, which no raster candidate can.
- **Wenrexa is the surprise contributor:** her *Space Modular Buildings Kit* (177 PNG sprites: 34 buildings, 14 turrets incl. 4 animated, mini asteroids, ships, bullets) **partially closes the "no CC0 top-down station art" gap** recorded in `environment.md:13,55` — though rendered, not flat-vector, so it is a station/debris-building source rather than a drop-in.
- **No licence risk anywhere in the recommendations.** Every candidate below is CC0 on the badge, so the CC-BY exception in `docs/ASSETS.md` is not needed. One row (*4 Flat Design Planets*) carries an attribution *notice* naming a third party while the badge is CC0 — CC0 governs, but it is flagged.
- **Format caveats that will bite on import:** Rawdanitsu, Wenrexa and technopeasant packs ship **JPG** (compression artefacts on smooth nebula gradients); the best Rawdanitsu tiled PNGs are 9-10 MB each (downscale on import); *Space Backdrop* is only 1280×800.

## Recommendations

1. **Do grimdark as a treatment layer, not a reskin.** Buy nothing outside this list and keep the Kenney baseline: (a) *Horror Texture Pack* transparent stain overlays (row 3) for rust / grime / bloodstain decals on hulls, wrecks and station tiles; (b) *Burnt Coal Ashes Tiling* (row 28) as the dead-belt / mining-debris ground; (c) a single graded palette constant in Godot (dark red → ash → black) applied via `modulate` + a colour-grade `CanvasLayer` so every layer shares one mood. This satisfies "flat-vector fit if darkened" without redrawing anything.
2. **Backdrop stack, three tiers, all CC0, all tileable or near-tileable.** Far layer: Rawdanitsu *Space Backgrounds 9* tiled variants (row 2) or LuminousDragonGames *Perfectly Seamless Night Sky* (row 25). Mid layer: Sauer2 *Starfield background* (row 7, horizontally seamless) with Fupi's `nightskyemission` (row 8) added as an additive glow. Hero/menu layer: beren77 *Space Backdrop* (row 4) and Wenrexa 4K (row 5). Swap one tile to change sector colour, as `environment.md:54` already proposes.
3. **Build the wreckage field from the one real wreck asset.** *Spacewreck* (row 1) as the central hulk, surrounded by Wenrexa dark asteroids (row 13) + Warspawn tintable strip (row 14) + OhjiroChan destruction overlays (row 15), with *Asteroids/Debris Set* (row 31) only if a pixel-debris look is acceptable. This is the closest achievable answer to "space hulk" in CC0.
4. **Take the vector route where palette fidelity matters.** SpriteAttack's SVG artpack (row 10) and CruzR's SVG kit (row 11) are the only candidates that can be recoloured to an exact Kenney-matched dark-red/ash palette at any zoom. If the grimdark direction is adopted formally, authoring the sector backdrop in vector is cheaper than grading five raster packs and keeping them consistent.
5. **Planets and the one signature object.** *HD Planet* (row 17, includes a black hole) + Bonsaiheldin's Red Planet and its colour variants (rows 18-19) + Rawdanitsu's planet sets (rows 21-22) cover shattered/burnt/dead worlds; grade toward ash and strip atmosphere layers. Add *4 Flat Design Planets* (row 24) if a natively flat planet is needed.
6. **Close the station gap in the interim.** Wenrexa's *Space Modular Buildings Kit* (row 12) is the first CC0 top-down station/debris module set found; it is rendered rather than flat, so treat it as a placeholder until the render-Kenney-3D-kits pipeline in `environment.md:55` exists.
7. **Do not chase an Openverse or itch answer for this need.** Both were re-checked and neither yielded a verifiable CC0 environment asset this pass (Openverse API 401 / UI 403; itch returns licence-less author pages). If Openverse must be covered, it needs an API token before it can be searched at all.
8. **Provenance.** Everything recommended is CC0, so no credits are owed; still run `create_asset_manifest` + `generate_credits` per batch and record the source page, and note the third-party attribution *notice* on row 24.
9. **Verify on a contact sheet before committing to a download batch:** three rows state no dimensions and must be inspected first — Fupi's sky textures (row 8), technopeasant's backdrop zip (row 26) and PucciGames' planet pack (row 23); likewise confirm the `-Tiled` PNGs (row 2) actually tile without a visible seam when region-repeated.
